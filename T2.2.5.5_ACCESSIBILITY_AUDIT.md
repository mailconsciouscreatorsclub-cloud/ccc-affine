#### Code Examples - Advanced Keyboard Navigation

```typescript
// Keyboard navigation state
const [focusedIndex, setFocusedIndex] = useState(0);

// ARIA IDs for relationships
const headingId = useId();
const detailsTitleId = useId();
const resultsAnnouncementId = useId();

// Keyboard event handling
const handleKeyDown = (event: KeyboardEvent<HTMLDivElement>) => {
  switch (event.key) {
    case 'ArrowDown':
      event.preventDefault();
      setFocusedIndex((prev) => Math.min(prev + 1, filteredCommands.length - 1));
      break;
    case 'ArrowUp':
      event.preventDefault();
      setFocusedIndex((prev) => Math.max(prev - 1, 0));
      break;
    case 'Enter':
      event.preventDefault();
      const command = filteredCommands[focusedIndex];
      if (command) onCommandSelect?.(command);
      break;
    case 'Escape':
      event.preventDefault();
      // Close palette
      break;
  }
};

// Option with proper ARIA
<div
  id={optionId(command)}
  role="option"
  aria-selected={index === focusedIndex}
  onClick={() => onCommandSelect?.(command)}
  className={clsx(styles.option, index === focusedIndex && styles.focused)}
>
  <span className={styles.trigger}>{command.trigger}</span>
  <span className={styles.description}>{command.description}</span>
</div>
```

#### Accessibility Strengths
1. **Keyboard Navigation:** Arrow keys, Enter, Escape properly handled
2. **Focus Management:** Visual focus indicator synchronized with `aria-selected`
3. **Search Functionality:** Accessible search with live result updates
4. **Category Filtering:** Keyboard accessible filter buttons
5. **Context Hints:** Command requirements communicated to screen readers

#### Suggestions for AAA Excellence
